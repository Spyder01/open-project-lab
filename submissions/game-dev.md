# 🎮 Game Development Submissions

Welcome to the **Game Development Submissions** section!  

Here you’ll find **projects contributed by developers** based on ideas from [categories/game-dev.md](../categories/game-dev.md). Each entry shows the implemented game, technologies used, and key features.  

All types of games are welcome — web-based, 2D/3D engines, Raylib projects, or any framework you prefer. Use the [implementation template](../templates/implementation-template.md) to submit your projects.  

✅ **Tips for contributors:**
- Link to the **original idea** you implemented.  
- Include the tech stack (Web frameworks, Unity, Godot, Raylib, or other engines).  
- Highlight any bonus challenges, levels, or unique features.
